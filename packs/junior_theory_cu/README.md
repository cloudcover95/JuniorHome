# JuniorTheoryCU

Community-run **theory credit union** pack for JuniorHome.

Not NCUA. Not a bank. Not deposits. Internal **share units** on a local BitNet-quant chain (`JuniorLLM.bitnet_pq`). `Params.secure` stays False.

Forum boards clone JuniorClimbs ForumMesh (events + gossip bundle), kinds retargeted to fund talk.

```
PYTHONPATH=. python -m packs.junior_theory_cu.cli init
PYTHONPATH=. python -m packs.junior_theory_cu.cli join nico
PYTHONPATH=. python -m packs.junior_theory_cu.cli propose nico "tool library"
PYTHONPATH=. python -m packs.junior_theory_cu.cli vote nico 0 yes
PYTHONPATH=. python -m packs.junior_theory_cu.cli board
```
