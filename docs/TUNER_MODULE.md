# Tuner module

Optional Home module. Not standalone. JuniorHome. Additive only. No flash. No stock ECU.

## Register
python3 -m web3node.tuner.module
Writes ~/.juniorhome/os/modules/tuner.json.

## Tile
ui/tuner.html. Reads ~/.juniorhome/os/tuner_dash.json. Optional. Not everyone's tea.
