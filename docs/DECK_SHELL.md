# JuniorDeck shell

Prototype plates stay: `cad/deck_well.scad`, `cad/deck_keys.scad`.
New: `cad/deck_shell.scad` (chassis + geode rings) and `cad/deck_trit_band.scad` (gamma channel).

Gamma drift is the empty channel, not a new silicon SKU.
