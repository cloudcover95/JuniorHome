# ROM module

Internal Home module. Drop a ROM you already have into ~/.juniorhome/rom/inbox.
Extensions: nes, sfc, smc, gb, gbc, gba, md, bin, iso, cue.
fetch false. bundled false. running false until a backend is present.
No ROM is downloaded. No BIOS is shipped. FrameForge is not this path.

```bash
python3 scripts/rom_module_prod.py
```
